# Data Modeling

This folder contains the dimensional data model designed for analytics and reporting.

Model Type:
- Star Schema

Tables:
- FactOrders
- DimCustomer
- DimProduct
- DimCategory
- DimDepartment

Relationships:
- One-to-Many relationships between dimensions and fact table
- Optimized for Power BI reporting and analytical queries

Purpose:
To provide a scalable and high-performance data model for business intelligence and supply chain analytics.
