# Dataset

This folder contains the source dataset used for the Supply Chain Analytics project.

Dataset Name:
DataCo Supply Chain Dataset

Source:
Kaggle - DataCo Smart Supply Chain for Big Data Analysis

Description:
The dataset contains order, customer, product, shipping, and geographic information used to analyze supply chain performance, sales trends, customer behavior, and logistics efficiency.

Key Data Domains:
- Customer Information
- Product Information
- Order Details
- Shipping Information
- Geographic Data
- Sales and Profit Metrics

Purpose:
The dataset was used to build an end-to-end analytics solution using Azure Data Lake Storage Gen2, Azure Data Factory, Azure Synapse Analytics, and Power BI.
