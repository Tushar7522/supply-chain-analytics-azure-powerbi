# Azure Synapse Analytics Data Warehouse

This folder contains the Azure Synapse Analytics warehouse design, SQL scripts, and data loading process.

Components:
- Fact Table (FactOrders)
- Dimension Tables (DimCustomer, DimProduct, DimCategory, DimDepartment)
- COPY INTO Scripts
- Dedicated SQL Pool Tables

Purpose:
To store cleansed and curated business data in a dimensional model for reporting and analytics.
